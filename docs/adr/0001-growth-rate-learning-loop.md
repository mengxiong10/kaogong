# 先用增长率单选题验证学习闭环

第二切片先交付“资料分析 → 增长率 → 一节课程 → 5 道原创单选题 → 统一交卷 → 解析与结果 → 刷新恢复”的完整闭环。第一版使用单选题以降低判分和交互复杂度，优先验证课程、练习、历史记录和反馈是否真正可用；题目领域模型继续保留多选能力，后续再扩展多选题、共享材料题组和整套模拟。

正确率以同一知识点、相近难度题目的首次作答为主要口径，重复练习单独统计；用时以相近难度题目的中位单题用时观察趋势，并结合正确率和不确定标记，避免把猜题或简单题造成的降时误判为能力提升。

## Consequences

- 第二切片不同时开发错题本、学习报告和整套模拟，只保留它们所需的数据基础。
- 后续统计必须保留首次作答与重复作答的区分。
- 薄弱模块需要基于持续记录和个人基线判断，不能由单次错误直接推断。
