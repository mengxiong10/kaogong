# 内容依据与目录边界

## 大纲依据

- 适用年份：2026；核对日期：2026-10-14。
- 来源：[湖北省2026年度省市县乡考试录用公务员公共科目笔试考试大纲](https://gdkfq.ezhou.gov.cn/gk/bmptlj/bm/qzsj/fdzdgk/zkly/202604/t20260417_761135.html)。
- 发布载体：鄂州葛店经济技术开发区政府网站；页面标注信息来源为湖北省人事考试网，日期为 2026-01-12。使用的是政府转载页面，未声称直接获取原始发布页。
- 已核对行政职业能力测验的六个考查模块：政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。

这里只建立分类并保留出处，不复制官方例题或解析；公开可浏览不等于题库获得复制授权。考试档案的来源许可标记为 unknown。

## 教学目录

下级目录来自 PRD 的教学设计，并非官方逐条考纲。种子包含 47 个知识点/方法和 6 个自建分类节点；所有下级节点标记 `classification: teaching`，模块标记 `classification: official`。

分类节点为理论与政策、综合常识、阅读与表达、数学运算、推理基础、统计与计算。方法节点包括截位直除、估算、差分法。增长率稳定 ID 为 `data-analysis-growth-rate`，用于第二切片。

首片仅初始化考试档案、模块、知识点和种子元数据。第二片增加增长率课程 v1 和 5 道原创单选题 v1；材料表仍为空，用户会话、答题、进度、错题表由实际使用产生。测试用题目仍只在测试文件中。

## 增长率内容核对

`src/data/growth-rate-content.ts` 保存自写课程与题目；来源为项目原创教学内容，许可标记 permitted，审核状态 verified。题目未复制大纲例题、真题或第三方解析。2026-10-16 对 5 题的唯一答案与解释逐项核算：

| 题目         | 核算                      | 答案 |
| ------------ | ------------------------- | ---- |
| 直接求增长率 | (150−120)/120 = 25%       | A    |
| 负增长       | (96−120)/120 = −20%       | A    |
| 反求基期量   | 135/1.125 = 120           | A    |
| 连续增长     | 1.15×1.10−1 = 26.5%       | B    |
| 比较增长率   | 20/80−30/150 = 5 个百分点 | A    |

课程覆盖题型识别、概念、公式、方法、例题、易错点和知识检测；练习按先易后难排序。审核是当前项目内的内容核算和自动化校验，尚未进行外部教研或真题命题专家复核。

## 后续内容入库

原创内容需要保存作者/来源说明、许可、版本和审核状态。AI 辅助内容先进入 draft，审核后 reviewed，完成答案与解析校验后 verified；生成成功不自动发布。练习池同时要求内容 verified、许可 permitted，共享材料也应用相同条件。

当前没有抓取、AI 调用或自动发布脚本。增长率内容采用固定、不可变版本；启动初始化只补充缺失版本，保留已有数据和作答历史。
