# 架构与数据契约

## 当前边界

仅移动端、个人使用、Local-first，无登录及远程服务器。当前开放首页学习概况、详细学习报告、知识体系、47 个知识点课程、六模块私人真题练习与错题本。宽屏沿用最大 480px 的移动布局。应用本身没有访问控制，包含私人题库的构建产物只能放在本人可访问的环境中。

## 分层与数据流

- `src/domain`：纯 TypeScript 类型、Zod Schema 和目录关联校验。允许依赖 Zod，独立于 UI 与数据库。
- `src/content`：内置目录、47 节课程与课程例题的 JSON；不在 TypeScript 中维护生产内容常量。
- `content-pipeline`：离线转换固定上游提交，生成 `public/content/bank` 与 `public/content/all-bank` 的版本化私人 JSON 与图片包。
- `src/data`：Dexie 表、内容包初始化和仓储。负责事务、引用校验与不可变内容版本。
- `src/features`：移动端功能页面，通过仓储和目录 Context 获取数据。
- `src/app`：路由、初始化状态、主题、应用壳和全局视觉变量。Zustand 只管理主题等界面状态。
- `src/components/ui`：官方 shadcn/ui CLI 生成的基础组件源码；页面通过 Tailwind 工具类组合使用，组件来源和样式约束见 `AGENTS.md`。

启动 → 初始化事务补齐目录、增长率内容版本及 46 节新课程与例题 → 读取首期资料分析题库清单并导入 → 仓储读取目录。首次进入某模块练习时，顺序校验并以分包事务导入该模块新增题包；已导入分包重试幂等，全部成功后记录模块提交版本。已存在版本与内置版本内容冲突时报错并保留现场；已导入同一来源提交时跳过分包，清单暂时不可读取时保留并使用已导入题库。首次导入失败显示错误与重试入口。首页不使用模拟学习数据。

## 核心模型

所有实体都有 strict Zod Schema；持久化写入与仓储读取均校验。Zod 校验形状，仓储校验跨实体引用。

| 实体             | 主键与关系                                      | 规则                                                        |
| ---------------- | ----------------------------------------------- | ----------------------------------------------------------- |
| ExamProfile      | id                                              | 地区、适用年份、大纲来源、核对日期                          |
| Module           | id → examProfileId                              | 官方分类，order 控制顺序                                    |
| KnowledgePoint   | id → moduleId / parentId                        | 自建教学树，同模块父子关系，无循环                          |
| Lesson           | [id, version] → knowledgePointId                | Markdown 内容、例题版本引用、来源与审核                     |
| LessonProgress   | lessonId → lessonVersion                        | 未开始、学习中、已完成、初步掌握；保存学习时的版本          |
| Question         | [id, version] → knowledgePointIds / materialRef | 多对多知识关联；单选与多选；Markdown 支持后续图片、公式渲染 |
| QuestionMaterial | [id, version]                                   | 多题共享材料，内容版本独立保留                              |
| PracticeSession  | id → questionRefs                               | 冻结题目顺序与版本；保存草稿、题号、不确定标记、累计耗时    |
| AnswerRecord     | id → sessionId / questionRef                    | 追加历史；同会话同题唯一；校验结果与冻结版本一致            |
| MistakeState     | questionId                                      | 复习状态、错误原因；错误次数和最近错误答案由作答历史计算    |

课程、题目和材料分别保存来源、地区、年份、许可状态、内容版本、审核状态。许可状态为 unknown / permitted / restricted；审核状态为 draft / reviewed / verified / source-provided / source-derived。两者不互相推导。原创内容仍须 verified 且 permitted。私人题库的题目及材料标记为 source-provided、third-party、unknown，表示仅信任上游给出的答案，未经独立核验；它们可在当前私人应用中创建训练会话，不会被改标为 verified 或 permitted。依据上游题目和解析整理的新课程标记为 source-derived、ai-assisted、unknown，直接在私人应用中展示，但不冒称已核验或取得再分发许可。

## 存储与接口

数据库名 `kaogong-learning`，版本 1。内容表使用 `[id+version]` 复合主键；答题表使用唯一 `[sessionId+questionRef.id]` 索引。种子事务只补齐缺失目录和课程内容版本，校验合并后的目录，保留已有条目和全部学习数据；seed-v1 元数据记录首次初始化时间。私人题库清单记录来源提交与分包数量；导入验证题目及材料引用、版本冲突和数量，在一个事务中写入，并记录 `private-bank-commit`。新增六模块题包按模块、分包事务增量导入，全部成功后记录 `module-bank-{moduleId}`。相同版本内容冲突回滚当前分包，已提交分包及历史记录保留；重试幂等补齐。内容包更新新增版本，不覆盖旧会话与作答。

- CatalogRepository：读取目录、学习进度，保存学习进度与错题状态。
- ContentRepository：增加课程、题目和材料版本，按版本读取题目和材料。相同版本相同内容幂等，变更内容必须增加版本号。
- PracticeRepository：创建、保存、恢复会话，追加与读取作答记录。保存会话不能改变题目顺序、版本、开始时间或解析模式；已完成会话不可修改。
- AnalyticsRepository：在只读事务中读取并校验作答、会话、历史题目版本、课程进度及错题状态；纯函数 `summarizeLearningReport` 计算首页概况与详细报告，不存储可漂移的统计快照。

学习报告的近期窗口为按完成时间排序的最近 10 套已完成练习。正确率分母只包含已作答题；`attemptNumber === 1` 为首次提交，首次留空后再答仍归重复作答。重做正确率与首次正确率分列；用时展示已作答题的中位数。累计完成题数按有过有效作答的稳定题目 ID 去重。已完成课程只计当前课程版本的 `completed` 和 `basic-mastery`，`learning` 单列。模块和知识点归属来自历史作答引用的题目版本；一道题可以计入多个知识点，但同一模块只计一次。页面给出正确数／已答数，不自动贴薄弱标签；上游答案和自动归类的局限在报告中说明。

错题本按稳定题目 ID 保存当前待复习／已掌握状态和可选的单个错误原因。只有 `incorrect` 交卷结果自动入本；未答与不确定标记不入本。错误次数、最近错误答案和历史由追加的 `AnswerRecord` 计算，不另存可漂移的计数。重做答对不自动标记掌握；再次答错会置为待复习并清空旧原因。状态修改使用事务和 Zod 校验，旧作答不改写。详情读取最近一次答错所引用的历史题目及材料版本；重做按稳定 ID 选择最新可练版本，最多五题，继续使用原有冻结会话、计时、批改和解析流程。当前没有可练版本时只展示历史详情。

`appendAnswer` 不接受由调用方决定的提交序号：仓储按稳定题目 ID 计算 `attemptNumber`，跨版本和会话累计，包含未作答提交。序号 1 表示首次提交；后续统计必须明确区分首次提交、重复提交及未作答，不能把未作答当成已完成题数。数据库事务保证并发提交只记账一次。

`submitSession` 根据已保存草稿，在单一事务中批改并写入全套答案、错误题的待复习状态与会话完成时间。未作答仍有独立记录，重复提交返回已有结果，不再次记账；失败回滚后可重试。练习页面不通过逐条 `appendAnswer` 交卷。`saveSession` 不允许直接把进行中会话改为已完成。

课程页按知识点创建真题会话，专项练习页可按模块创建真题会话，原资料分析快捷入口仍可使用。首次进入模块练习时先导入对应题包；不再创建原创增长率题练习。旧会话仍按冻结的题目版本恢复和展示，作答历史不改写。`advanceSessionTime` 纯函数累计当前题用时，`summarizeAnswers` 和 `summarizePracticeHistory` 分别计算本套结果、按难度区分的首次与重复作答正确数、中位用时和不确定标记次数。答题页面在切题、选择、定时更新、标签页隐藏及页面退出时尽力保存累计用时，后台标签页暂停计时；结果页按会话冻结版本读取解析。浏览器强制关闭时最后不足一秒的计时写入无法保证，但最近一次已保存的用时仍可恢复。单套最多 5 题，不据此推断稳定正确率或薄弱模块。

课程页面显示最新的 verified/permitted 原创版本或 source-derived/unknown 私人版本；若版本更新，当前学习进度重新进入 learning 并引用新版本。Markdown 数学公式由 KaTeX 输出 MathML，样式使用 Tailwind 工具类，不增加全局 CSS 入口。

共享材料题以材料为单位选择未练过的最多五道单选题；独立题按五题一组选择；原图在练习与结果页展示。全部题目都练过后从首组重做。上游没有可靠难度字段，首批标记 `unrated`，难度统计单列显示，不伪造简单/中等/较难。首期 1001 道题仍关联资料分析综合；新增题自动关联现有教学节点，归类不代表人工审核。增长率课程新增版本 2 更新练习提示，版本 1 和原创题版本仍留存，供旧学习进度与会话引用。

## 迁移与安全恢复

未来结构变化增加 Dexie version，提供对应迁移测试。内容更新新增版本，暂不提供删除内容或历史的公共接口。已有目录校验失败时保留数据库现场并提示错误；重试只重新初始化，不清空数据库。

数据仅属于当前浏览器与站点来源。当前尚未实现备份、导入导出或跨设备同步。自动化测试使用独立临时数据库，测试题不进入应用种子。
