# 内容依据与目录边界

## 大纲依据

- 适用年份：2026；核对日期：2026-10-14。
- 来源：[湖北省2026年度省市县乡考试录用公务员公共科目笔试考试大纲](https://gdkfq.ezhou.gov.cn/gk/bmptlj/bm/qzsj/fdzdgk/zkly/202604/t20260417_761135.html)。
- 发布载体：鄂州葛店经济技术开发区政府网站；页面标注信息来源为湖北省人事考试网，日期为 2026-01-12。使用的是政府转载页面，未声称直接获取原始发布页。
- 已核对行政职业能力测验的六个考查模块：政治理论、常识判断、言语理解与表达、数量关系、判断推理、资料分析。

这里只建立分类并保留出处，不复制官方例题或解析；公开可浏览不等于题库获得复制授权。考试档案的来源许可标记为 unknown。

## 教学目录

下级目录来自 PRD 的教学设计，并非官方逐条考纲。种子包含 47 个知识点/方法和 6 个自建分类节点；所有下级节点标记 `classification: teaching`，模块标记 `classification: official`。

分类节点为理论与政策、综合常识、阅读与表达、数学运算、推理基础、统计与计算。方法节点包括截位直除、估算、差分法。增长率稳定 ID 为 `data-analysis-growth-rate`，用于第二切片。

首片仅初始化考试档案、模块、知识点和种子元数据。第二片增加增长率课程 v1 和 5 道原创单选题 v1；当时材料表仍为空。当前私人题库已补入共享材料与题目。2026-10-17 新增增长率课程 v2，仅将末尾练习提示改为资料分析真题练习，v1 和原创题均保留供历史引用；新建练习只使用真题。用户会话、答题、进度、错题表由实际使用产生。测试用题目仍只在测试文件中。

## 增长率内容核对

`src/content/growth-rate.json` 保存自写课程与题目；来源为项目原创教学内容，许可标记 permitted，审核状态 verified。题目未复制大纲例题、真题或第三方解析。2026-10-16 对 5 题的唯一答案与解释逐项核算：

| 题目         | 核算                      | 答案 |
| ------------ | ------------------------- | ---- |
| 直接求增长率 | (150−120)/120 = 25%       | A    |
| 负增长       | (96−120)/120 = −20%       | A    |
| 反求基期量   | 135/1.125 = 120           | A    |
| 连续增长     | 1.15×1.10−1 = 26.5%       | B    |
| 比较增长率   | 20/80−30/150 = 5 个百分点 | A    |

课程覆盖题型识别、概念、公式、方法、例题、易错点和知识检测；练习按先易后难排序。审核是当前项目内的内容核算和自动化校验，尚未进行外部教研或真题命题专家复核。

## 后续内容入库

原创内容需要保存作者/来源说明、许可、版本和审核状态。AI 辅助内容先进入 draft，审核后 reviewed，完成答案与解析校验后 verified；生成成功不自动发布。练习池同时要求内容 verified、许可 permitted，共享材料也应用相同条件。

当前没有抓取或 AI 调用脚本。增长率内容采用固定、不可变版本；启动初始化只补充缺失版本，保留已有数据和作答历史。

## 私人资料分析题库

首批选择 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti) 的固定提交 `278984401124db40da5163a31275b8deb9c282f4`。上游自报资料分析共 8115 题；实际转换并通过结构与图片完整性检查的发布包为 **1001 道单选题、204 份共享材料、4597 张图片**。湖北卷优先，其他省考和国考补足。上游表格与公式部分以图片存在，当前只展示原图，不提取图中数值。答案和解析沿用上游，未经独立复核，未标定难度。

上游仓库公开可读，但没有查到题目及图片的明确再分发许可。内容包保留 `license: unknown`、`reviewStatus: source-provided` 与具体试卷来源链接，仅供本人可访问的应用使用；包含此包的 `public/content/bank`、构建产物和仓库副本都不应公开提供。源码中的许可与审核字段独立记录，不能将来源答案等同于 verified，也不能把个人用途等同于 permitted。若将来公开发布应用，须移除私人内容包或另行取得授权。

## 六模块课程与真题扩充

2026-10-17 按用户决定沿用上述固定提交，新增 46 节课程，覆盖六大模块现有全部 47 个可学节点。课程提纲保存在 `src/content/course-outlines.json`，指定例题保存在 `src/content/example-selection.json`，最终课程和例题保存在 `src/content/all-courses.json`。新课程结合原题、上游解析与项目编写的识别、规则、步骤、易错和检测说明；上游答案与解析不做独立核验，课程标记 `source-derived`、`ai-assisted`、`unknown`，直接在私人应用中可见。原增长率原创课程 v1/v2 及历史记录保留。

`public/content/all-bank` 新增去重后的 25978 道单选题、597 份共享材料及 35107 张引用图片；加上首期 1001 题，共 26979 道来源单选题。解析失败、答案标记不一致、图片缺失、来源重复或资料分析无共享材料的题目不入包，原因与数量见 `content-pipeline/output/all-bank-report.json`。题目按原始小类和题干关键词自动关联自建教学节点，关联不代表人工确认；未能细分的题归入对应模块较宽的知识点。政治、法律、时政等旧题按原考试年份理解，不作为现行政策或法律建议。

首期资料分析包仍在启动时导入；六模块扩充包在首次进入对应模块练习时按分包导入。内容仅供本人访问，未取得题目或图片再分发许可。`pnpm content:check` 校验内容结构、数量、知识点覆盖、例题引用和已打包图片，不校验答案事实正确性。
